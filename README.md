# 棉小柔官网

这是棉小柔智能肤质毛巾机的滚动叙事品牌官网原型。参考用户指定的 Kage 3D 空间叙事方式，重新组织为九个连续场景章节：晨光入场、靠近识肤、读懂状态、产品结构、毛巾遇水舒展、抽屉送达预演、回到清晨日常、触感细节、品牌终章。页面不接管滚轮；自然滚动可正向/反向驱动同一条 Three.js 相机路径与场景时间轴。

## 实现结构

- `site/index.html`：可爬取的中文正文与九幕章节、真实肤质 UI 视频、结构引线锚点、章节轨道、动效开关及行动号召。
- `site/styles.css`：暖白/浅雾蓝品牌视觉、固定画布与多层景深、章节文字转场、右侧九幕导航、移动端底部轨道、无障碍焦点与减少动态适配。
- `site/js/main.mjs`：网站交互编排、当前章节/进度、视频滚动同步、低配回退、动效开关和页面后台恢复。
- `site/js/scroll-timeline.mjs`：以真实章节顶部为时间锚点，在章节进入时同步导航、文字、场景和视频；每个章节到下一章节边界完成一个连续、可逆的相机旅程段。
- `site/js/cinematic-world.mjs`：Three.js 常驻空间、Catmull–Rom 相机/目标/产品轨迹、相邻场景交叉淡化、背景与透明前中景平面、粒子、扫描光、光环/涟漪、产品分件展开和随模型投影的标注。
- `site/assets/`：项目自有 Logo、轻量 WebP 场景层、视频和产品 GLB，供本机 Preview 与静态构建直接读取。

## 动效与降级

画面采用一个持续存在的 Three.js 世界，而不是逐屏切换独立海报。每个章节是沿空间路径排列的 scene module；自然滚动映射到章节顶部之间的相机位置、观察目标、产品姿态、背景/前景权重与局部特效。章节导航、当前章节标记与原生视频的滚动进度以同一边界为准。结构分件只做页面叙事中的视觉预演，标签通过真实 GLB 节点投影定位；“抽屉送达”位移同样只是展示用动效，并非经工程确认的实机行程。

桌面采用更高的渲染像素比，移动端降低分辨率并限帧；系统减少动态效果、用户关闭氛围动效、WebGL 不可用或省流/低配设备均有静态/轻量回退。尊重 `prefers-reduced-motion`，用户也可显式开启或暂停氛围动效。主体文案、锚点导航和视频原生控件不依赖 WebGL 才能阅读。

Three.js 0.170.0 与 GLTFLoader 使用版本固定的 jsDelivr ES module。若 CDN 或 WebGL 不可用，页面退回项目产品透明图与 HTML 内容；如后续要离线或长期稳定部署，应将 Three.js 及 GLTFLoader 固定版本本地打包。

## 本地预览

Manus Desktop 中可使用项目 Preview。手动预览时，将静态服务根目录指向 `site/` 并选择一个空闲的 loopback 端口；Session 临时端口由 WebDev Preview 配置管理，不写入项目源文件。

静态路由清单位于 `site/manus-routes.json`。

## 对外使用前必须确认

肤质 UI 动效使用项目提供的检测/结果设计稿，原稿中的演示数值、肤质结论和建议尚未作为获批的产品数据或承诺；页面已在对应章节标注此边界。Blender 爆炸拆件与位移、抽屉运动为视觉预演，轴心、行程及装配关系未经工程验证，页面已明确不代表实机动作。未经品牌、产品、合规与工程确认，不应把当前预览公开发布。

## 构建/发布边界

官网是无后端、无数据库的静态页面，输出目录为 `site/`，可使用 WebDev 的无构建步骤输出配置。本轮仅用于本机/Manus Preview 与托管版本同步；`publishing.auto_publish` 保持关闭，不进行公开发布。
