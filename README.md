# 棉小柔官网

这是棉小柔智能肤质毛巾机的单页品牌官网原型，按滚动章节组织内容，使用项目自有 Logo、产品外观、背景/透明前景、真实 UI 演示、毛巾舒展视频和 Blender 结构素材。Kage 仅作为滚动镜头与景深分层的交互参考，页面代码、美术和产品叙事均为棉小柔项目自建。

## 本地预览

从项目根目录启动静态服务：

```bash
python3 -m http.server 3000 --bind 127.0.0.1 --directory site
```

访问 `http://127.0.0.1:3000/`。静态路由清单在 `site/manus-routes.json`。

## 实现说明

- `site/index.html`：可直接读取的中文首屏与章节内容、元数据和资源入口。
- `site/styles.css`：洁净科技感的品牌视觉、分层氛围、章节及响应式布局。
- `site/js/main.mjs`：滚动状态、视频进度、场景光效及 Three.js 结构预演。
- `site/assets/`：为本地 Preview 与静态构建准备的轻量化项目素材。
- Three.js 0.170.0 与 GLTFLoader 使用版本固定的 jsDelivr ES module；若 CDN 或 WebGL 不可用，页面回退至项目产品透明图，章节文本和导航仍可用。

## 对外使用前必须确认

肤质 UI 动效使用项目提供的检测/结果设计稿，原稿中的演示数值、肤质结论和建议尚未作为获批的产品数据或承诺；网页已在对应章节标注此边界。Blender 爆炸拆件与位移为视觉预演，盖板轴心、抽屉行程及装配关系未获工程验证；页面已明确不代表实机动作。未经品牌、产品、合规与工程确认，不应把当前预览公开发布。

## 构建/发布边界

官网是无后端、无数据库的静态页面；静态输出目录为 `site/`，可用 WebDev 的无构建步骤输出配置。当前项目配置 `publishing.auto_publish=false`；本次仅预览与版本同步，不执行公开发布。
